# helloashif/homebrew-tap

Homebrew casks for my apps.

```sh
brew install --cask helloashif/tap/ip-tracker
```

| Cask | App |
|---|---|
| `ip-tracker` | [IP Tracker](https://github.com/helloashif/ip-tracker-desktop) — track your public IP address over time |

`Casks/ip-tracker.rb` is updated automatically by the IP Tracker release workflow.
